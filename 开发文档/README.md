## 五、技术栈基线（已确认）

| 项     | 选型                                                   |
| ----- | ---------------------------------------------------- |
| 后端    | Python 3.11 + FastAPI + SQLAlchemy 2.0 / Pydantic v2 |
| 异步    | Celery + Redis                                       |
| 存储    | MySQL 8.0 + Elasticsearch（+ 可选向量）                    |
| 计算    | Spark 3.X（SQL执行/质量/调度）                               |
| LLM   | 千问 Qwen 3.8（API，NL2SQL/口径问答）                         |
| 元数据采集 | 本地建表文件 + Hive 直连 双模式                                 |
| 血缘    | 平台自建（表级）                                             |
| 告警    | 平台内通知                                                |
